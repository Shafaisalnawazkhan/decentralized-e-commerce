# Decentralized Authentication for Branded Products using Blockchain Technology (DAFBPUBCT)

> **Award-Winning 3D Interactive Web Application & Django Backend Protocol**

DAFBPUBCT is a realistic, immersive, interactive 3D web platform built to combat the global $4.2 Trillion counterfeit market across luxury timepieces, haute couture leatherware, fine jewelry, artisanal fragrances, and high-end electronics using decentralized blockchain smart contracts, NFC/QR cryptographic encoding, and real-time WebGL 3D telemetry.

---

## 🎨 Technology Stack

### Frontend & 3D WebGL Engine
- **Core Languages**: HTML5, CSS3, JavaScript (ES6+)
- **UI Framework**: Bootstrap 5.3 & Cyberpunk Glassmorphic Design Token System
- **Typography**: Space Grotesk (Headings), Poppins (UI), Inter (Body)
- **3D Graphics & Animations**: Three.js (WebGL), Chart.js, Lenis Smooth Scroll, GSAP
- **Color Theme**: Deep Space (`#0B1023`), Electric Cyan (`#00E5FF`), Neon Mint (`#00FFB3`), Cyber Violet (`#6D5DFD`)

### Backend Architecture
- **Framework**: Django 4.2+ & Django REST Framework
- **Database**: SQLite (Development) / MySQL / PostgreSQL (Production ready)
- **Cryptographic Engine**: SHA-256 Hash Verification & Smart Contract State Telemetry
- **API Endpoints**: `/api/verify/<product_id>/`, `/api/dashboard-stats/`, `/api/recent-blocks/`

## 🌐 5-Page Application Structure

### Page 1: HOME
- **3D Hero Scene**: Rotating 3D Blockchain Cube with glowing wireframe core, floating luxury brand gem spheres, particle constellation, and interactive mouse parallax tilt.
- **Headline & CTAs**: *"Authenticate Every Product with Blockchain"*, dual CTA buttons (*Verify Product*, *Explore Technology*).
- **Sections**: How It Works (4-Step Pipeline), Core Features Grid, Live Telemetry Bar, Statistics, and Brand Testimonials.

### Page 2: ABOUT BLOCKCHAIN
- **3D Earth Scene**: Interactive 3D Holographic Globe with connected supply chain node checkpoints (Geneva, Paris, Tokyo, NYC, Antwerp).
- **Supply Chain Timeline**: **Manufacturer → Distributor → Retailer → Customer → Instant Verification**.
- **Metrics**: Counterfeit market stats, zero-knowledge proofs, and smart contract specs.

### Page 3: PRODUCT VERIFICATION DASHBOARD
- **Interactive Verifier Terminal**: Serial input, quick test presets (`SWISS-7709`, `PARIS-8821`, `GRASSE-4091`, `TOKYO-3310`, `JEWEL-5520`, `FAKE-9900`), and QR image drag-and-drop zone.
- **3D Product Inspector**: Interactive 3D luxury item mesh with metallic shaders and animated 3D holographic laser scanner beam.
- **Verification Output**: Dynamic Holographic Green (Authentic) vs Red (Fraud Warning) results with full hash audit trail and warranty confirmation.

### Page 4: BLOCKCHAIN DASHBOARD
- **Real-Time Analytics**: Products Registered, Verified Authentic, Fake Items Blocked, and Live Block Height Ticker (`#1,894,204`).
- **Interactive 3D Charts**: Product Category Distribution (Doughnut), Monthly Authentications (Bar Chart), and Real-time Network TPS Line Chart.
- **Node Constellation**: 3D particle constellation canvas & glass activity stream.

### Page 5: CONTACT & TEAM
- **Core Engineering Team**: 3D interactive flip glass cards for Lead Developer, WebGL Engineer, and Security Auditor.
- **Institution Metadata**: Department of Computer Science & Engineering, Major Project Supervisor details, and technology stack breakdown.
- **3D Glass Contact Form**: Encrypted contact form with interactive floating states.

## 🚀 Quick Start & Installation

### 1. Environment Setup
```bash
# Clone repository and enter directory
cd c:\Users\Rida\Desktop\DAFBPUBCT

# Activate virtual environment
.venv\Scripts\activate    # Windows PowerShell
```

### 2. Run Database Migrations
```bash
cd backend\django_auth
python manage.py migrate
```

### 3. Launch Development Server
```bash
python manage.py runserver 8000
```
Open your browser and navigate to **`http://127.0.0.1:8000/`**.
